# 小组作业二 英文文本作者识别方法指导

根据英文文本判断作者属于 `EAP`、`HPL`、`MWS` 三类，并输出每一类的概率。先用词和字符 TF-IDF 配合线性模型，建立速度快、便于解释的基线，再考虑更复杂模型。

## 数据结构

目录 `datasets/ml-hw2-group/` 中，训练集 14684 行，字段 `id,text,author`；测试集 4895 行，字段 `id,text`。训练作者分布为 `EAP 5925`、`MWS 4533`、`HPL 4226`，无空字段。

提交模板 `submission_example.csv` 的列为 `id,EAP,HPL,MWS`。这三个输出字段对应概率，不能只输出一个作者名称或三个未归一化分数。样例中的 one-hot 值是格式示例，不代表应该把全部预测硬化成 0 或 1。

## 验证与评价

先以作者标签进行 80% 与 20% 的分层划分，再做五折 StratifiedKFold。当前没有完全相同的训练文本，但可对归一化后的重复句、相似引文进一步检查；若识别出同来源段落，按来源分组进行额外验证。

本地重点监控多分类 LogLoss，同时记录 Accuracy 和混淆矩阵。LogLoss 为真实类别预测概率负对数的均值，过度自信的错误会受到较大惩罚；官方主指标仍需核实。词表、词频和 IDF 只能在训练折拟合，不能把训练与测试拼接后拟合向量器。

## 最小基线

1. 先用训练类别频率生成固定概率基线。
2. 建立 `TfidfVectorizer + LogisticRegression` 的 Pipeline，使用词级 unigram 与 bigram。先保留基本标点与词形信息，不做激进停用词删除或词干化。
3. 建立字符级 TF-IDF，例如 3 至 5 字符片段，配合逻辑回归。字符模式可能反映词尾、拼写和标点风格。
4. 在训练折内用 FeatureUnion 组合词与字符特征，比较与各自单独使用的差别。

初始可试词级 `min_df=2`、`ngram_range=(1,2)`，字符级 `ngram_range=(3,5)`，逻辑回归 `C=1,3,10`。词表上限按内存设置，保持稀疏矩阵，不要 `.toarray()` 把全文特征转为稠密矩阵。

## 改进路线

加入文本长度、标点比例、平均词长、大写比例等少量风格统计，并使用独立缩放步骤。对照保留和删除停用词：功能词本身可能有作者识别价值，不能把通用文本清洗流程直接当成最佳方案。

可比较 MultinomialNB，或经校准的线性 SVM。SVM 的 decision function 不是概率；校准数据必须来自训练折内部的额外划分。若课程允许，再以英文预训练编码器微调作为增强方案，记录输入长度与截断比例，避免长句信息被无声截断。

融合时按 `EAP,HPL,MWS` 显式对齐类别概率。选择融合权重后检查 LogLoss 是否改善，而非仅检查硬分类准确率。用置信度高但错误的句子寻找主题依赖、罕见词和短句问题。

## 提交与小组交付

模型的 `classes_` 顺序不应靠猜测。用类名找到对应概率列后填入模板，保证 4895 行、ID 顺序正确、每行概率和约等于 1、所有值有限且位于 0 至 1。仅为数值稳定进行微小裁剪时，裁剪后再次归一化。

分工可分别负责词特征、字符与风格特征、神经模型或概率校准、验证与报告。共用折划分，保存折外三类概率，便于公平融合。报告包含特征消融、各作者召回率、概率质量及典型误判句子。
