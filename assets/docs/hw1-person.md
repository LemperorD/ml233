# 个人作业第 1 题：红葡萄酒质量预测方法指导

课程依据：[作业说明 PDF](2026研究生机器学习大作业说明.pdf) 第 4 页；[课程邀请入口](https://www.kaggle.com/t/8c018b4ff37d4782b84f650e62f50a49) 来自 PDF 第 13 页。文档与代码目录按 PDF 题号统一编号；本地数据目录保留下载时的名称，对应关系见[总览](README.md#题目仓库编号与评分标准)。个人与团队各四选一；报告、截止时间及打包要求统一见[总览](README.md)。

利用十一项理化指标预测葡萄酒质量。PDF 已明确按 RMSE 评分，采用连续回归，提交保留小数；不因原始标签是整数而改用分类准确率选模。

## 数据与风险

目录为 `datasets/ml-hw2-person/`，对应竞赛标识 `ml-hw2-personal`，注意本地目录与竞赛名称并不完全相同。训练集 1119 行，测试集 480 行，无空字段。

输入为 `fixed acidity`、`volatile acidity`、`citric acid`、`residual sugar`、`chlorides`、`free sulfur dioxide`、`total sulfur dioxide`、`density`、`pH`、`sulphates`、`alcohol`；`id` 仅用于对齐，`quality` 是目标。训练质量分布为 `3:4`、`4:37`、`5:484`、`6:436`、`7:145`、`8:13`。

仅按十一项输入比较，有 123 行属于重复特征行。重复样本若分到训练与验证两侧，会使验证过于乐观。还需区分重复样本同标签与冲突标签，不宜直接删除所有重复记录。

## 验证与指标

将十一项特征的完整组合生成分组 ID，使用 GroupKFold 做五折验证，使同特征样本留在一折。可额外报告普通随机五折的结果，用于解释重复样本对估计的影响；主要结论使用分组结果。

以课程主指标 RMSE 选择模型，同时记录 MAE。RMSE 为 `sqrt(mean((y_pred-y_true)^2))`；先用训练折均值预测作为 RMSE 基线，用训练折中位数作为 MAE 对照。稀有高低质量样本单独分析误差。不要仅凭 `quality` 是整数就四舍五入预测。

若将有序分类的概率期望作为回归候选，最终仍按连续预测的 RMSE 比较。标签 3 只有 4 个样本，不能声称普通五折分层能让每折都含该类别；检查每折质量分布并报告稀有标签的误差。

## 实施顺序

1. 删除输入中的 `id` 和 `quality`。保留字段名称中的空格，检查训练测试列顺序。
2. 建立 `StandardScaler + Ridge` 的 Pipeline，比较 `alpha=0.1,1,10,100`。每折独立拟合标准化，不能先在全数据上缩放。
3. 比较随机森林或 ExtraTrees，限制树深和叶节点最小样本数；树模型通常不需要标准化。
4. 比较梯度提升回归或 CatBoost，小数据从深度 4 到 6、较小学习率和早停开始，不要直接堆很多深树。
5. 固定验证方案后，才尝试少量特征交互，例如游离与总二氧化硫的比例。比例必须加安全分母；通过消融确认作用。

本任务只有一千余条训练样本，不推荐从大型神经网络起步。岭回归的系数、树模型重要性与残差图更容易支持课程报告。

## 误差分析与改进

按真实质量、酒精含量区间和重复组查看残差。检查模型是否把质量 3、4、8 一律预测为 5 或 6，以及异常理化值是否主导误差。缺少证据时不要把罕见样本直接视为脏数据。

比较原始目标与有序分类的期望预测值，或者比较线性与树模型平均；仅在固定折外预测上选择融合比例。训练标签范围 3 到 8 是观测事实，预测截断到该范围是否有利应通过验证检验，不应当作已知官方范围。

## 提交与报告

读取 `submission_example.csv` 并生成 `submission.csv`，列为 `id,quality`，480 行。PDF 说明表中的 `ID` 是示意，导出保持本地模板的小写 `id`。按 `id` 对齐，保留小数，不含索引、空值或无穷值。使用全量训练数据重训时，沿用交叉验证选出的配置。

报告至少包含：目标直方图、重复样本统计、均值基线与 Ridge、一个树模型的分组验证比较、按质量分段的误差。不把训练集分数当作泛化性能。
