# 个人作业一 食物图像分类方法指导

根据食物照片预测十个类别。训练图只有 912 张，优先验证冻结预训练特征与小规模微调，避免一开始训练大型网络。使用预训练模型前先确认课程是否允许；限制预训练时，使用同一验证集比较小型 CNN 与传统特征方法。

## 数据与读取

- 目录：`datasets/ml-hw1-person/`，竞赛标识 `ml-hw1-person`。
- `train.csv` 为 912 行，包含 `id,label`；`test.csv` 为 608 行，仅有 `id`。
- 图片分别在 `train_images/` 和 `test_images/`；`id` 已包含 `.jpg`，不要再次添加扩展名。
- 图片均为 RGB，尺寸不统一。输出模板 `submission_example.csv` 有 608 行，列为 `id,label`。

十类及训练数量为：`shawarma 98`、`burger 95`、`hot_dog 99`、`crepes 99`、`tacos 97`、`pani_puri 94`、`churros 99`、`falafel 81`、`pad_thai 68`、`pretzel 82`。保存固定 `class_to_idx`，预测时反向映射成原始英文字符串。

## 验证与评价

先按类别分层留出约 20% 验证集，固定种子和图片 ID。可再做三折分层验证评估稳定性；通过文件哈希或感知哈希发现重复、近重复图片时，先分组再划分。先划分原图，再在训练集应用随机增强。

本地记录 Accuracy、Macro-F1 和混淆矩阵。Accuracy 衡量整体正确率，Macro-F1 帮助发现数量较少类别是否被忽略；官方主指标需确认。查看食物被裁掉、背景干扰、相似外观等错误，而不是只看一个总分。

## 最小基线

1. 用 PIL 按 CSV 的 ID 加载图片，执行 `convert("RGB")`。训练使用温和的随机裁剪、水平翻转和颜色扰动；验证使用确定性缩放与裁剪。
2. 若允许预训练，使用 ResNet18 的固定特征提取器，按权重对应的输入归一化规则处理图片。先比较整图缩放与中心裁剪，避免把细长图像中的食物完全裁掉。
3. 缓存训练和验证特征，用逻辑回归学习十分类。这个基线训练快，适合先排除标签、路径和提交格式问题。
4. 再将网络最后一层替换为十维输出，使用交叉熵。先只训练分类头，再解冻最后一组卷积层，以较低学习率微调。

可从分类头学习率 `1e-3`、骨干 `1e-4`、批量 16 或 32 开始，最多先试 20 轮，按验证指标早停。它们是起始配置，不是已经验证的最佳参数。无预训练方案可先用三到四层卷积加全局平均池化，控制参数量。

## 改进实验

| 实验 | 改动 | 需要回答的问题 |
| --- | --- | --- |
| A | 固定特征加线性分类器 | 图像特征是否已经足够区分类别 |
| B | 解冻最后一层网络 | 微调是否比固定特征稳定提升 |
| C | 适度颜色扰动和裁剪 | 是否减少背景依赖，是否误伤主体 |
| D | 两个种子或骨干的概率平均 | 错误是否互补，收益是否值得成本 |

每次检查训练和验证差距。训练准确率高而验证停滞时，先减少模型容量、增强或解冻范围，再增加训练轮数。不要因为类别差异不大就默认使用强类别权重；是否使用应由逐类召回率决定。

## 提交与报告

按测试 CSV 的 ID 生成预测，再与模板按 ID 对齐。列名必须是 `id,label`，共 608 行，标签只能取上述十种值。保存训练标签顺序，防止把类别编号错误地当作类别名称输出。

报告保存混淆矩阵和若干预测错误图片，解释至少两组容易混淆的食物。提交前确认每张测试图恰好预测一次，验证阶段未使用随机训练增强。
